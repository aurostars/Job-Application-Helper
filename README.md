# 秋招网申助手

秋招网申助手是一款适用于 Chrome 和 Edge 的浏览器扩展，用于集中管理求职资料、识别招聘表单并快速填入个人信息、教育经历、实习项目和简历文件。

## 快速安装

### 环境要求

- Chrome 或 Edge 116 及以上版本
- Node.js 20.19 及以上，或 Node.js 22.12 及以上
- npm

推荐安装最新的 Node.js LTS 版本。

### 一键安装并构建

下载项目后，在项目根目录运行对应脚本：

- macOS：双击 `一键安装依赖.command`
- Windows：双击 `一键安装依赖.bat`

脚本会依次完成：

1. 检查 Node.js 和 npm。
2. 使用 `npm ci` 安装锁定版本的依赖。
3. 运行全部自动化测试。
4. 构建可加载的 `dist/` 目录。

### 加载浏览器扩展

1. 打开 Chrome 或 Edge 的扩展程序管理界面。
2. 开启页面内的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目根目录下的 `dist/` 文件夹。
5. 将“秋招网申助手”固定到浏览器工具栏，方便使用。

代码若有更新，重新运行一键脚本或 `npm run build`，再到扩展管理页，先停用再启用一次扩展即可。

## 如何使用

### 配置个人资料

1. 点击浏览器工具栏中的插件图标。
2. 点击“设置个人信息”进入设置页。
3. 依次填写基本信息、教育经历、实习与项目、自定义信息。
4. 点击页面底部“保存”，右上角出现“保存成功”后即可关闭页面。

AI 配置不是必需项。未配置 AI 时，基本信息管理、JSON 简历导入、信息浮窗、复制和常规表单填充仍可使用。

### 导入简历

在“简历上传”中选择文件：

- JSON：无需配置 AI，可直接导入结构化资料。
- PDF、DOCX、Markdown、TXT：支持本地基础解析；配置 AI 后可获得更完整的结构化识别。

解析后的资料会显示在设置页中，确认内容后点击保存。

### 填写网申表单

1. 打开招聘网站的申请或简历填写页面。
2. 点击浏览器工具栏中的插件图标。
3. 在插件弹窗中点击“一键填充表单”。
4. 插件识别当前页面字段并填入已保存的信息。
5. 自动填充后请人工核对下拉选项、日期、隐私声明和提交内容。

插件不会在网页右下角注入悬浮按钮，整页填充统一从浏览器工具栏的插件弹窗启动。

如果某个字段没有正确识别，可打开“网申信息浮窗”，单独复制或填入基本信息、教育经历、实习经历、项目经历和自定义信息。

### AI 框选补填

AI 框选补填用于处理整页填充后仍为空白、命名复杂或重复出现的字段，使用前需要先在“AI 设置”中配置可用的模型服务。

1. 打开需要补填的网申页面。
2. 点击浏览器工具栏中的插件图标。
3. 点击“AI 框选补填”，插件弹窗会关闭，网页进入区域选择状态。
4. 将鼠标移动到“基本信息”“教育经历”“实习经历”或“项目经历”等表单模块上，紫色边框会显示当前识别区域。
5. 单击整个模块，或按住鼠标拖出一个自定义矩形区域。
6. 插件只收集选中区域内仍为空白的字段，结合已保存资料交给 AI 匹配并填入。
7. 页面右下角会显示扫描、匹配和填入进度；需要停止时点击“终止”，按 `Esc` 可在选择区域时取消。

AI 框选补填不会覆盖已经有值的输入框。完成后仍需人工检查日期顺序、下拉选项和生成内容。

### 使用信息浮窗

信息浮窗适合逐个处理自动填充未识别的特殊字段。写入操作必须按以下顺序完成：

1. 保持网申页面打开，点击浏览器工具栏中的插件图标。
2. 点击“打开信息浮窗”，右侧会打开独立的信息窗口。
3. 回到网申页面，先用鼠标点击需要填写的输入框、文本域或下拉框，使光标停留在该字段中。
4. 再到信息浮窗中展开对应的教育、实习、项目或自定义信息。
5. 点击具体字段或整条自定义信息，例如“学校”“专业”“公司”“岗位”，插件会把该字段值写入刚才聚焦的网页输入框。
6. 若页面不允许直接写入，内容会自动复制到剪贴板，可回到网页手动粘贴。

“置顶小窗”可在浏览器支持文档画中画时让信息窗口保持在网页上方。

### 备份与同步

设置页的“数据与同步”提供两种备份方式：

- “导入完整数据”：选择以前导出的 JSON，检查通过后确认覆盖本地资料。
- “导出完整数据”：下载当前全部资料的 JSON 备份。

完整备份包含个人资料、简历原文件、AI 配置和 API Key，以及 WebDAV 同步设置（服务器地址、用户名、密码）。字段匹配缓存和同步状态不会写入备份文件。

导入带 WebDAV 设置的备份会覆盖当前的连接配置，导入前的摘要中会标明；旧备份没有该字段时保留现有配置。

上传到 WebDAV 的同步文件不包含 WebDAV 凭据，密码不会存到远端；同步下载也不会覆盖本地的连接配置。

## 功能说明

| 功能 | 说明 |
|---|---|
| 资料管理 | 保存基本信息、教育经历、实习经历、项目经历、技能、证书和自定义信息 |
| 一键填充表单 | 从插件弹窗启动，自动识别当前网页的招聘表单字段并填入资料 |
| AI 框选补填 | 框选表单模块或自定义区域，只对其中空白字段执行 AI 匹配与填入 |
| 信息浮窗 | 先聚焦网页输入框，再点击浮窗中的单条资料完成逐字段写入；失败时自动复制 |
| 简历解析 | 支持 PDF、DOCX、Markdown、TXT 和结构化 JSON |
| 简历上传 | 在支持的网页文件控件中使用已保存的简历原文件 |
| AI 辅助 | 可选配置兼容 OpenAI 接口的模型，用于简历解析、复杂字段匹配、框选补填和开放题生成 |
| JSON 备份 | 版本化导入、导出，导入前验证格式并显示摘要 |
| WebDAV 同步 | 保存后自动同步，使用 ETag 防止跨设备静默覆盖 |
| 冲突处理 | 本地和远端都发生变化时，由用户选择使用本地或远端版本 |

## WebDAV 配置

在“数据与同步”中填写：

- WebDAV 服务器地址
- 用户名
- 密码或第三方应用密码

首次点击“测试连接”时，插件会创建或确认远端目录：

```text
job-application-helper/
└── job-application-helper.json
```

保存同步设置后，点击“立即同步”完成首次上传。启用自动同步后，保存个人资料、解析简历、保存 AI 配置或导入完整备份都会排队同步。

同步规则：

- 只有本地变化：上传本地版本。
- 只有远端变化：下载远端版本。
- 两端都变化：停止覆盖并显示冲突选择。
- 同步失败：保留已成功保存的本地数据。

坚果云通常使用：

```text
服务器地址：https://dav.jianguoyun.com/dav/
用户名：坚果云登录邮箱
密码：第三方应用管理中生成的应用密码
```

如果返回 401，请检查账号和应用密码；如果返回 403、404 或 409，请确认地址是可写的 WebDAV 根目录，而不是普通网页或分享链接。

## 手动安装与开发

### 安装依赖

```bash
npm ci
```

没有 `package-lock.json` 时才使用：

```bash
npm install
```

### 常用命令

```bash
npm test
npm run build
npm run lint
npm run dev
```

- `npm test`：运行备份格式与 WebDAV 同步测试。
- `npm run build`：类型检查并生成 `dist/`。
- `npm run lint`：运行静态代码检查。
- `npm run dev`：启动 Vite 开发服务，扩展调试仍需构建后加载 `dist/`。

## 数据说明

- 默认数据保存在浏览器扩展的 `chrome.storage.local`。
- JSON 导入文件上限为 20 MiB。
- 手动备份和 WebDAV 文件为明文 JSON，可能包含个人信息、简历和 AI API Key。
- 只有主动配置并启用 WebDAV 后，数据才会上传到用户自己的 WebDAV 服务。
- 卸载扩展或清除扩展数据前，建议先导出完整备份。

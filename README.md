# 秋招网申填写浏览器插件

一个帮助求职者自动填写网申表单的 Chrome/Edge 浏览器插件。

## 功能特性

- ✅ **自动识别表单字段** - 智能检测网页中的招聘表单字段
- ✅ **一键填充信息** - 点击按钮自动填充个人信息
- ✅ **信息管理面板** - 便捷管理个人资料、教育经历、工作经验
- ✅ **简历解析** - 支持上传 PDF/DOCX/MD/TXT 格式简历，自动提取信息
- ✅ **简历自动上传** - 自动识别并上传简历文件
- ✅ **React + TypeScript** - 现代化技术栈，类型安全

## 技术栈

- React 18 + TypeScript
- Vite 构建工具
- Chrome Extension Manifest V3
- Ant Design UI组件库
- PDF.js / Mammoth.js / Marked (文件解析)

## 开发指南

### 一键安装依赖并构建（推荐）

项目根目录已提供一键脚本，双击即可完成「安装依赖 + 构建 dist/」：

- macOS：双击运行 `setup.command`
- Windows：双击运行 `setup.bat`

> 脚本会优先使用 `npm ci`（与 `package-lock.json` 对齐），然后执行 `npm run build`。

### 1. 安装依赖（手动）

```bash
npm install
```

### 2. 构建项目

```bash
npm run build
```

构建后的文件在 `dist/` 目录中。

### 3. 加载到浏览器

1. 打开 Chrome/Edge 浏览器
2. 访问 `chrome://extensions/`（Edge 访问 `edge://extensions/`）
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目的 `dist/` 目录

## 使用说明

### 首次使用

1. 安装插件后，点击插件图标
2. 点击"设置个人信息"进入配置页面
3. 填写基本信息（姓名、手机、邮箱等）
4. 可选：上传简历文件，系统会自动解析并填充信息

### 填写网申表单

1. 访问任何招聘网站的申请页面
2. 页面右下角会出现"一键填充"浮动按钮
3. 点击按钮，插件会自动识别并填充表单字段
4. 简历文件会自动上传到对应的上传控件

## 注意事项

1. **数据隐私**: 所有数据存储在本地浏览器，不会上传到任何服务器
2. **文件大小**: Chrome 本地存储限制为 5MB，建议简历文件小于 3MB
3. 第一次构建前需要添加插件图标到 `public/icons/` 目录

## 开发调试

修改代码后需要：
1. 重新运行 `npm run build`
2. 在扩展管理页面点击刷新按钮
3. 刷新目标网页

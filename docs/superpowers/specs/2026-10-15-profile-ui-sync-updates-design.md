# 个人资料界面与即时同步改进设计

## 背景

当前扩展已提供个人信息维护、教育与经历管理、信息窗口快捷填充，以及基于 WebDAV 的数据同步。本次改动在保持现有数据兼容性的前提下，重新组织部分设置页内容，补充常用字段、字段复制能力和 Popup 即时同步入口。

## 目标

- 优化自定义信息的新增入口和排序操作。
- 将专业技能与荣誉奖励从经历页拆分到独立的“技能荣誉”页。
- 补充“主要课程”和“兴趣爱好”字段，并贯通保存、展示与自动填充链路。
- 为信息窗口中的每个字段提供独立复制入口，复制时不触发自动填充。
- 在 Popup 顶部提供即时同步入口，并将同步冲突交由设置页处理。

## 非目标

- 不重构整个设置页为全局配置驱动表单。
- 不改变现有简历、技能、荣誉和同步数据的存储结构。
- 不在 Popup 内实现冲突解决弹窗。
- 不改变点击字段主体执行自动填充的既有行为。

## 方案选择

采用最小范围调整方案：复用现有组件、数据模型、列表移动逻辑和同步冲突判断，只抽取确有复用价值的复制交互。该方案无需迁移既有技能与荣誉数据，改动范围清晰，回归风险最低。

未采用以下方案：

- 全面重构字段渲染为配置驱动：长期维护性较好，但明显扩大本次改动范围。
- 各区域分别实现排序、复制和同步交互：实现直接，但会产生重复代码和不一致状态。

## 设置页信息架构

### 导航调整

相关标签按以下顺序排列：

1. 个人基本信息
2. 教育经历
3. 实习项目
4. 技能荣誉
5. 自定义信息
6. 其余现有页面保持原有相对顺序

原“实习与项目”标签更名为“实习项目”。

### 技能荣誉页

新增“技能荣誉”标签页，页面依次展示：

1. 专业技能
2. 荣誉奖励

专业技能继续使用现有 `skills` 数据和 `SkillsEditor`，荣誉奖励继续使用现有 `awards` 数据和 `AwardsSection`。本次只调整 UI 归属，不迁移或转换数据。

### 自定义信息

“添加”按钮从页头移动到全部自定义信息卡片之后。新增条目仍追加到数组末尾，因此新增后按钮继续位于最后一张卡片下方。

每张自定义信息卡片的标题区增加上移和下移按钮：

- 上移：与前一项交换位置。
- 下移：与后一项交换位置。
- 第一项禁用上移。
- 最后一项禁用下移。
- 移动后立即通过现有状态保存链路持久化。

按钮样式与教育经历、实习经历、项目经历中的排序按钮保持一致。

## 数据字段扩展

### 教育经历：主要课程

在 `EducationInfo` 中增加可选字段 `majorCourses?: string`。设置页的每段教育经历增加“主要课程”输入项，采用多行文本，适合填写以顿号、逗号或换行分隔的课程。

信息窗口的教育经历区域展示非空的主要课程。表单自动填充逻辑增加对“主要课程”等常见字段标签的识别。

### 个人基本信息：兴趣爱好

在 `PersonalInfo` 中增加可选字段 `hobbies?: string`。个人基本信息设置页增加“兴趣爱好”多行文本输入项。

信息窗口的个人基本信息区域展示非空的兴趣爱好。表单自动填充逻辑增加对“兴趣爱好”“爱好”等常见字段标签的识别。

### 兼容性

两个新字段均为可选字段，已有简历对象缺少字段时按空值处理，不需要数据迁移。现有导入、导出、备份和 WebDAV 同步以完整简历对象为单位，应保留新增字段；相关测试需验证字段不会在序列化与恢复过程中丢失。

## 信息窗口复制交互

每个可展示字段最右侧增加一个小型复制按钮。字段主体和复制按钮是两个独立点击区域：

- 点击字段主体：保持现有自动填充行为。
- 点击复制按钮：阻止事件冒泡，仅将当前字段展示的完整内容写入剪贴板，不发送自动填充消息。

复制成功后，该字段的复制图标变为“✓”，持续约 1 秒后恢复。每个字段的反馈状态独立；复制其他字段不会取消已有字段的计时。

空值字段沿用现有规则不展示。剪贴板写入失败时不显示“✓”，保留复制图标，避免给出错误的成功反馈。

复制交互应封装为轻量共用单元，由个人基本信息、教育经历、经历、项目、技能、荣誉与自定义信息字段共同使用，避免各区域重复实现状态与事件阻止逻辑。

## Popup 即时同步

### 入口与状态

在 Popup 标题栏右上角增加“同步”按钮，位置对应需求截图红框区域。按钮支持以下状态：

- 默认：同步
- 执行中：同步中…，按钮禁用，防止重复提交
- 成功：短暂显示同步成功或成功图标，随后恢复默认
- 普通失败：在按钮附近显示简短错误提示，允许用户重试

### 同步流程

点击按钮后，使用当前 WebDAV 配置立即发起一次双向同步，并复用共享同步模块的本地哈希、远端哈希和上次同步哈希判断。

处理结果如下：

- 同步成功：更新成功状态，不跳转页面。
- 检测到冲突：立即打开设置页 `?tab=data-sync`，由用户在既有同步界面选择冲突解决方案。
- 尚未配置同步：打开设置页 `?tab=data-sync`，引导用户完成配置。
- 网络、鉴权或 WebDAV 服务异常：留在 Popup，展示失败提示，不将普通错误误判为冲突。

同步任务由共享同步能力执行，避免把生命周期绑定在 Popup 组件上；Popup 关闭不应主动取消已发起的同步。

## 组件与职责边界

- 设置页主组件：调整标签名称、顺序、页面归属和自定义信息列表交互。
- 技能荣誉组合组件：只负责组合现有专业技能与荣誉奖励编辑器。
- 数据类型：仅增加两个可选字段，不改变已有字段语义。
- 信息窗口字段组件：负责字段主体填充入口、复制按钮及单字段复制反馈。
- 共享同步模块：继续负责同步判断和执行，不包含 Popup 展示逻辑。
- Popup：负责触发同步、映射结果到 UI 状态，以及在冲突或未配置时打开数据同步设置页。

## 错误处理

- 排序操作遇到首尾边界时不修改数组。
- 剪贴板写入失败时不显示成功状态，也不触发自动填充。
- 同步执行期间阻止重复请求。
- 冲突与未配置状态跳转设置页；网络、鉴权和服务错误留在当前 Popup 并提示。
- 新字段缺失或为空时不影响旧数据加载、信息窗口渲染与自动填充。

## 测试策略

采用测试先行方式覆盖以下行为：

1. 自定义信息上移、下移和首尾边界。
2. 设置页存在“实习项目”和“技能荣誉”，且技能荣誉位于实习项目之后。
3. 专业技能与荣誉奖励只出现在技能荣誉页，不再出现在实习项目页。
4. 主要课程和兴趣爱好能够保存、重新读取并在信息窗口展示。
5. 新字段能够经过导出、备份恢复和同步序列化而不丢失。
6. 点击复制按钮只写入剪贴板，不发送自动填充消息。
7. 复制成功图标约 1 秒后恢复；失败时不显示成功状态。
8. Popup 手动同步覆盖成功、未配置、冲突、普通失败和重复点击分支。
9. 自动填充能够识别主要课程与兴趣爱好常见标签。

完成后运行相关单元测试、TypeScript 构建和扩展构建，确认设置页、信息窗口和 Popup 均可正常打包。
